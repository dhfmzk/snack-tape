# SnackTape

좋아하는 YouTube 장면만 골라 이어보는 Chrome Extension MVP입니다.

## 기능

- 현재 YouTube 영상의 시작점과 끝점을 찍어 구간을 저장합니다.
- 저장한 구간을 선택한 시퀀스 안에서 순서대로 이어 재생합니다.
- 같은 영상의 다음 구간은 이동 없이 재생 위치를 바꾸고, 다른 영상은 현재 탭을 해당 YouTube 영상 주소로 이동합니다.
- 편집 페이지에서 시퀀스 생성, 이름 변경, 삭제, 선택, 구간 수정, 삭제, 위아래 이동을 할 수 있습니다.
- YouTube 썸네일 미리보기와 JSON 가져오기/내보내기를 제공합니다. 가져오기는 기존 목록을 지우지 않고 뒤에 추가합니다.
- 자동 재생이 허용되지 않으면 YouTube 페이지 위에 작은 `계속 재생` 버튼을 표시합니다.

## 설치 및 빌드

```bash
node scripts/clean.mjs
npx --yes --package typescript@5.9.3 tsc --noEmit -p tsconfig.json
node scripts/build.mjs
```

`node scripts/build.mjs`는 내부에서 `npx --package esbuild@0.25.12`를 호출해 `dist/` 폴더에 Chrome에서 불러올 수 있는 확장 프로그램 파일을 만듭니다.

테스트는 아래처럼 실행합니다.

```bash
node scripts/clean.mjs
npx --yes --package typescript@5.9.3 tsc -p tsconfig.test.json
node --test tests/*.test.mjs
```

`npm install` 없이 실행하는 흐름을 기본으로 잡았습니다. 이미 의존성을 설치해둔 환경에서도 같은 명령을 그대로 사용할 수 있습니다.

## Chrome에 불러오기

1. Chrome에서 `chrome://extensions`를 엽니다.
2. 오른쪽 위의 개발자 모드를 켭니다.
3. `Load unpacked`를 누릅니다.
4. 이 저장소의 `dist/` 폴더를 선택합니다.

## 사용 방법

1. YouTube 영상 페이지를 엽니다.
2. 영상을 재생하다가 확장 프로그램 팝업을 엽니다.
3. `시작점 찍기`를 누릅니다.
4. 원하는 위치로 이동한 뒤 `끝점 찍기`를 누릅니다.
5. `조각 추가`를 눌러 선택한 시퀀스에 저장합니다.
6. 다른 YouTube 영상에서도 같은 흐름으로 구간을 추가합니다.
7. `이어보기`를 누르면 선택한 시퀀스의 구간들이 순서대로 재생됩니다.
8. `편집 열기`에서 구간을 수정하거나 JSON을 가져오고 내보낼 수 있습니다.

## 수동 QA 체크리스트

1. YouTube 영상 페이지에서 팝업을 열었을 때 제목, 영상 ID, 현재 시간이 보이는지 확인합니다.
2. `시작점 찍기`와 `끝점 찍기` 후 draft 시간이 화면에 표시되는지 확인합니다.
3. 팝업을 닫았다 다시 열어도 같은 영상에서는 찍어둔 시작점/끝점이 유지되는지 확인합니다.
4. 끝점이 시작점보다 앞이면 한국어 오류가 나오는지 확인합니다.
5. `조각 추가` 후 선택한 시퀀스에 카드가 추가되고 draft가 비워지는지 확인합니다.
6. 두 개 이상의 YouTube 영상에서 구간을 추가한 뒤 `이어보기`를 누릅니다.
7. 같은 영상의 다음 구간은 탭 이동 없이 재생 위치가 바뀌는지 확인합니다.
8. 다른 영상의 다음 구간은 현재 탭이 이동하고 이어 재생되는지 확인합니다.
9. 마지막 구간이 끝난 뒤 재생 상태가 정리되고 탭이 닫히지 않는지 확인합니다.
10. 자동 재생이 허용되지 않는 경우 `계속 재생` 버튼으로 직접 재생을 이어갈 수 있는지 확인합니다.
11. 편집 페이지에서 이름 변경, 삭제, 위로, 아래로, 수정, 저장, 취소가 카드 단위로 동작하는지 확인합니다.
12. JSON 내보내기 결과를 다시 JSON 가져오기로 불러올 수 있는지 확인합니다.
13. YouTube가 아닌 페이지에서는 `YouTube 영상 페이지에서 사용할 수 있어요.`가 보이고 `편집 열기`를 사용할 수 있는지 확인합니다.

## 알려진 한계

- 일부 영상은 브라우저나 YouTube 정책 때문에 자동 재생되지 않을 수 있습니다.
- 일부 영상은 YouTube 제공 상태, 지역 제한, 로그인 상태, 연령 제한 등에 따라 재생되지 않을 수 있습니다.
- 이 MVP는 YouTube 중심으로 구현되어 있고 Google Drive, TwitCasting, 자막, 태그 필터는 지원하지 않습니다.
- 이 MVP는 로컬 저장소만 사용하며 계정, cloud sync, 공유 링크는 지원하지 않습니다.
- 시작점/끝점 draft는 같은 브라우저 세션 안에서 같은 영상에 한해 유지됩니다.

## 안전 원칙

- SnackTape은 사용자가 이미 브라우저에서 볼 수 있는 YouTube 영상의 재생 위치만 제어합니다.
- 광고, DRM, 로그인 벽, 지역 제한, 연령 제한, 비공개 영상 접근 제어를 우회하지 않습니다.
- 영상을 다운로드하거나 재업로드하지 않습니다.
- 사적 콘텐츠를 스크래핑하지 않습니다.
- YouTube UI처럼 위장한 조작 버튼을 삽입하지 않고, 자동 재생이 허용되지 않을 때 작은 `계속 재생` 버튼만 표시합니다.
